# 三分钟演示脚本

## 0:00–0:25 问题

打开浏览器工作台。说明规则并不是代码才会出错：不同部门分别写下“未成年人禁止高额订单”和“VIP 大额订单快速放行”，单独看都合理。

## 0:25–0:55 一键分析

点击“执行取证”。展示 972 条边界路径、风险问题和覆盖率。强调没有调用模型或服务器，结果完全由本地确定性引擎生成。

## 0:55–1:30 最小反例

点击 `RS1001`：

```json
{
  "age": 0,
  "tier": "vip",
  "region": "cn",
  "amount": 1000,
  "digital": false
}
```

解释为什么两条优先级均为 100 的规则同时命中，并分别给出 `deny` 与 `allow`。

## 1:30–1:55 修复并重跑

把 VIP 快速放行规则的优先级从 100 改为 90，重新执行。冲突消失，未成年保护规则明确胜出。说明 RuleScope 不替业务作决定，而是要求业务把含糊的优先关系写清楚。

## 1:55–2:20 决策轨迹

进入“决策轨迹”，输入一个成年 VIP 欧盟数字商品订单。展示每条规则为何命中或跳过，以及 `decision` 和 `discount` 如何独立解析。

## 2:20–2:40 多场景

依次切换费用报销、内容访问和保险受理，说明同一引擎适用于审批、资格、权限、折扣和风控。

## 2:40–3:00 MoonBit 与工程质量

展示终端：

```bash
moon check --target js --deny-warn
moon test --target js
moon run cmd/rulescope --target js -- checkout
```

说明领域模型、边界生成、执行、诊断、行为 diff 和测试由 MoonBit 实现；浏览器加载 MoonBit JS 后端生成的模块，仓库包含完整文档、CI 和 Apache-2.0 许可证。
